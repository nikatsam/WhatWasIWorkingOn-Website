How to find recently opened files in Windows

Forgot the filename or where you saved it? Start with the recent lists Windows and your apps already provide.

By Nikatsam · Updated 1 October 2026

Windows doesn’t keep one perfect list of every file you have ever opened. Recent-item lists depend on Windows settings, the app that opened the file, and the type of item. Try these options in order.

1. Check Home in File Explorer

Open File Explorer and select Home in the navigation pane. Depending on your Windows version and settings, the Home view may show recent files alongside favourites and frequently used folders. On Windows 10, look under Quick access for frequent folders and recent files.

If the file doesn’t appear, it may have been hidden from recent items, opened from a location that Windows doesn’t track there, or removed from the list. This view is useful for a quick check, but it isn’t a complete work log.

2. Look in the app you used

Word, Excel, image editors, code editors, and other desktop apps often have a Recent or Open recent screen. This can be the fastest route when you remember which app you used, even if you don’t remember the document’s exact name.

3. Search for a name or file type

If you remember part of the filename, an extension such as .pdf, or the folder where it might live, use Windows Search or File Explorer search. Searches find files that currently exist; they don’t necessarily tell you which file you worked on most recently.

4. Use a searchable recent-work history

When you need to connect a file with the app and time you used it, a local recent-work history can be more convenient than checking separate app lists. What Was I Working On? combines supported Windows recent-activity signals into a searchable overlay and history window. Press Alt + Space to open the overlay, search by a remembered word or extension, then open the file or its containing folder.

It is not a disk index and cannot promise to show every item. It uses recent activity Windows and supported apps make available, so availability depends on those signals.

Keep recent lists useful

  • Use a consistent project folder structure.
  • Pin important work in the app or tool you use.
  • Remember a distinctive word, extension, or application to narrow a search.
  • If privacy matters, review the Windows and app settings that control recent-item lists.
In a hurry?

Try File Explorer Home first. If you’ve been switching between several apps and need one searchable view, see the quick workflow guide.

How local file history can stay private

A useful recent-work history needs context. It should also be clear about what it sees, where it stores it, and what it does not do.

By Nikatsam · Updated 1 October 2026

“Recent files” can mean several different things: a list kept by an individual app, links Windows creates for recently opened items, or a separate history database. Knowing the difference helps you make an informed choice about privacy.

Recent activity is not the same as scanning a disk

A recent-work tool can use activity signals that Windows and supported apps already expose—for example, Windows Recent Items, application jump lists, the foreground app, or an app’s recent-document list. That is different from walking every folder on a drive and cataloguing its contents.

What Was I Working On? is designed around those existing signals. It does not index your disks or inspect document contents. Like any recent-activity tool, it may still handle names, paths, app names, and timestamps so it can show and search your activity.

Local storage and encryption

The app keeps its history in encrypted local storage using SQLCipher-based encryption, with the database key protected using Windows DPAPI. This is intended to protect stored history on the device; it is not a claim that no other software on an already-unlocked Windows account could ever access information.

The app does not upload file history, require an online account, or rely on cloud sync for its core features. Its core recent-work features are intended to work offline.

Controls that put you in charge

  • Pause tracking: stop recording new activity while leaving saved history available.
  • Retention: choose how long history is kept.
  • Clear history: remove history stored by the app.
  • Recovery scans: start them only when you choose; a selected candidate is copied into encrypted app storage before it is opened.

What clearing app history does not do

Clearing this app’s history does not automatically clear Windows Recent Items or the recent-document lists maintained by Word, Excel, or other apps. Those are separate sources with their own settings. Similarly, pausing this app’s tracking does not change those Windows or app-level lists.

Make a privacy decision that fits your device

If you share a Windows account or use a managed work PC, consider the device’s account and access settings as well as any recent-file feature. Review retention periodically and pause or clear app history whenever that better fits the situation.

Plain-language summary

What Was I Working On? stores its own history locally and encrypted. It uses recent-activity signals; it does not read the contents of your documents or upload your file history.
